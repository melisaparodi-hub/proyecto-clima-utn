## Descripción

Este proyecto analiza datos de temperatura global histórica. A partir del archivo `clima.csv`, se calculan algunos indicadores básicos de temperatura y se genera un gráfico para ver la evolución histórica.

## Dataset utilizado

Se utilizó el dataset **Global Temperature**, disponible en DataHub:

https://datahub.io/core/global-temp

## Estructura del repositorio

- `/datos`: contiene el archivo `clima.csv`.
- `/scripts`: contiene el script `analisis_clima.py`.
- `/resultados`: contiene el gráfico generado y el archivo `resumen.txt`.
- `README.md`: contiene la descripción general del proyecto.

## Ejecución del script

Desde Google Colab, ubicarse en la carpeta del repositorio y ejecutar:

```bash
python scripts/analisis_clima.py
```
